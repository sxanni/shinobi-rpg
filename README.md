# shinobi-rpg

Browser-based Naruto-inspired turn-based RPG combat prototype.

## Current Build

v49.5 Codex working build

## Features

- Turn-based combat
- Stance system
- Combo system
- Status effects
- Will Power abilities
- Summons with stance requirements
- Equipment durability and attrition
- Inventory, reserve gear, and throwable items
- Narrative battle log
- Mobile-friendly tooltip support

## Run Locally

Open `index.html` in a browser.

## Project Files

- `index.html` - main playable build
- `sprites/` - sprite assets used by the current build
- `DEV_ROADMAP.md` - development roadmap, completed systems, and remaining work
- `CHANGELOG.md` - version notes for major build updates

## Status

This is an active prototype build. The current version is still a single-file implementation and may be refactored later into separate HTML, CSS, and JS files.
